# 🧑‍💻  IBM Cognos Analytics Dashboard – Developer Survey Insights

A data analytics dashboard built with **IBM Cognos Analytics** as part of a hands-on learning project. The dashboard visualizes data from a developer survey and is organized into three tabs: **Current Technology Usage**, **Future Technology Trend**, and **Demographics**.

---

## 📁 Dashboard Tabs

### 1. Current Technology Usage
Visualizes the technologies developers are actively using today:
- **Top 10 Languages Worked With** - JavaScript leads (8,687), followed by HTML/CSS and SQL
- **Top 10 Databases Worked With** - MySQL is most popular (5,469), ahead of PostgreSQL and MongoDB
- **Platform Word Cloud** - Highlights platforms like Linux, Windows, AWS, Android, and Docker
- **Top 10 Web Frameworks** - Bubble chart comparing jQuery, React.js, Angular, and others

### 2. Future Technology Trend
Explores what technologies developers want to work with next year:
- **Top 10 Languages Desired Next Year** - JavaScript remains #1 (6,630); Python and TypeScript gaining ground
- **Top 10 Databases Desired Next Year** - PostgreSQL tops the list (4,328), followed by MongoDB and Redis
- **Platform Desired Next Year** - Treemap showing Linux, Docker, and AWS as top choices
- **Top 10 Web Frames Desired Next Year** - React.js and Vue.js are the most desired frameworks

### 3. Demographics
Provides background on the survey respondents:
- **Gender Distribution** - 93.5% Men, 6.5% Women
- **Respondent Count by Country** - Choropleth world map showing geographic distribution
- **Age Distribution** - Line chart; most respondents are aged 14–28
- **Education Level by Gender** - Bachelor's degree holders are the largest group (5,341 men, 412 women)

## 🎯 Purpose

This project was created to **learn and practice IBM Cognos Analytics**, including:
- Connecting to datasets
- Building interactive charts (bar, pie, bubble, treemap, word cloud, map)
- Organizing visualizations into a multi-tab dashboard layout
- Applying filters and formatting
